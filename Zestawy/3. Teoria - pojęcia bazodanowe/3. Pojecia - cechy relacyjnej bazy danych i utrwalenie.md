## Zadanie 4 — Analiza schematu *(na papierze)*

Baza **turniejów e-sportowych**:

```
druzyny    ( 🔑 id INT, nazwa VARCHAR(40) UNIQUE, kraj CHAR(2), data_zalozenia DATE )
zawodnicy  ( 🔑 id INT, nick VARCHAR(20) UNIQUE, imie VARCHAR(20),
             🔗 id_druzyny INT → druzyny.id,
             rola ENUM('kapitan','gracz','rezerwowy'), data_urodzenia DATE )
turnieje   ( 🔑 id INT, nazwa VARCHAR(60), gra VARCHAR(40),
             data_startu DATE, pula_nagrod DECIMAL(10,2) )
udzial     ( 🔑🔗 id_druzyny INT → druzyny.id,
             🔑🔗 id_turnieju INT → turnieje.id,
             zajete_miejsce TINYINT NULL )
```

a) Jakie **encje** opisuje ta baza? Która tabela jest **tabelą łączącą**?
b) Wypisz klucz główny każdej tabeli. Która ma klucz **złożony**?
c) Wypisz wszystkie **klucze obce** (`tabela.kolumna → tabela.kolumna`).
d) Wskaż dwa **klucze kandydujące** (inne niż `id`).
e) Określ związki: drużyna–zawodnik, drużyna–turniej. Uzasadnij.
f) Jaki jest **stopień** tabeli `zawodnicy`?
g) Jaka jest **dziedzina** atrybutu `pula_nagrod`? Dlaczego `DECIMAL`, a nie `FLOAT`?
h) Dlaczego `zajete_miejsce` może być `NULL`?
i) Czy da się usunąć drużynę, która brała udział w turnieju? Co odpowie baza i jak nazywa się ta reguła?
